5. **alert_record** - 预警记录表
6. **audit_log** - 审计日志表
7. **system_config** - 系统配置表

## 已创建的索引

- user表: 唯一索引(phone, email)
- elder_guardian表: 索引(elder_id, guardian_id), 唯一约束(elder_id, guardian_id)
- emotion_record表: 复合索引(elder_id, analyzed_at)
- alert_record表: 复合索引(elder_id, status, created_at)
- audit_log表: 复合索引(user_id, created_at)

## 验证查询

### 1. 查看所有用户
```sql
SELECT id, username, role, status FROM user;
```

### 2. 查看情感记录统计
```sql
SELECT emotion_type, COUNT(*) as count 
FROM emotion_record 
GROUP BY emotion_type;
```

### 3. 查看待处理预警
```sql
SELECT id, elder_id, alert_type, severity, message, created_at 
FROM alert_record 
WHERE status = 'PENDING';
```

### 4. 查看老人及其监护人关系
```sql
SELECT e.name as elder_name, u.username as guardian_name, eg.relationship, eg.authorized
FROM elder e
JOIN elder_guardian eg ON e.id = eg.elder_id
JOIN user u ON eg.guardian_id = u.id;
```
