## 通用说明

### 请求配置

- 所有接口均使用 JSON 格式传输
- 前端开发环境使用 Mock 数据，生产环境需对接后端真实接口
- 认证通过后需在请求头携带 Token：`Authorization: Bearer {token}`

### 响应格式

```json
{
  "code": 200,
  "message": "操作成功",
  "data": { }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | number | 状态码，200表示成功 |
| message | string | 响应消息 |
| data | object | 响应数据 |

### 状态码说明

| 状态码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 201 | 资源创建成功 |
| 400 | 请求参数错误 |
| 401 | 未授权/认证失败 |
| 403 | 无权限访问 |
| 404 | 资源不存在 |
| 409 | 资源冲突 |
| 500 | 服务器内部错误 |

## 认证模块

### 1. 邮箱登录

**请求信息**

| 项目 | 内容 |
|------|------|
| URL | `POST /api/auth/login/email` |
| Content-Type | `application/json` |

**请求参数**

```json
{
  "email": "user@example.com",
  "password": "123456"
}
```

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| email | string | 是 | 用户邮箱 |
| password | string | 是 | 登录密码 |

**成功响应**

```json
{
  "code": 200,
  "data": {
    "accessToken": "mock_token_1",
    "user": {
      "id": 1,
      "username": "admin",
      "role": "admin",
      "name": "系统管理员",
      "phone": "13800000001",
      "email": "admin@eldermood.com",
      "avatar": "https://api.dicebear.com/7.x/avataaars/svg?seed=admin",
      "isActive": true
    }
  }
}
```

**失败响应**

```json
{
  "code": 401,
  "message": "邮箱或密码错误"
}
```
