# 一、整体布局（PC 端优先）

采用**左右分栏 + 顶部导航**的通用后台布局（Vue + Element Plus 最常用）


```
顶部导航栏（固定）
├─ 左侧侧边栏（固定，菜单）
│  └─ 右侧主内容区（滚动）
```

# 二、页面结构分区（一共 6 块）

## 1. 顶部导航栏（固定置顶）

- 项目名称：**居家老人情感分析及可视化系统**
- 导航菜单首页、情感监测、数据可视化、预警中心、老人管理、系统设置
- 右侧：头像、用户名、退出登录、消息通知

## 2. 左侧侧边栏（固定）

- 一级菜单折叠 / 展开
- 菜单列表：
    
    - 首页概览
    - 实时情感监测
    - 历史数据可视化
    - 预警通知
    - 老人信息管理
    - 数据采集上传
    - 系统设置
    - 帮助中心
    

## 3. 首页「概览大屏」（最重要页面）

采用**上下 + 左右混合布局**

- 顶部：**数据总览卡片**（4 个）
    
    - 今日监测人数
    - 今日预警次数
    - 平均情感健康分
    - 系统运行状态
    
- 左侧：**情感趋势折线图**（近 7 天）
- 右侧：**情感类型占比饼图**
- 底部：**最新预警列表 + 最近监测记录**

## 4. 实时情感监测页

- 上半部分：**老人选择 + 实时采集区**
    
    - 语音录制按钮
    - 图片上传
    - 文本输入框
    - 开始分析按钮
    
- 下半部分：**分析结果展示**
    
    - 当前情感标签（开心 / 低落 / 焦虑 / 平静等）
    - 置信度
    - 多模态判断依据（文本 / 语音 / 图像 分项得分）
    - 情感健康评分
    

## 5. 数据可视化页

- 筛选栏：老人姓名、时间范围（日 / 周 / 月）
- 图表区（占满大部分宽度）
    
    - 情感趋势曲线
    - 每日情感统计柱状图
    - 时段分布热力图
    
- 下方：历史记录表格

## 6. 预警中心页

- 顶部：筛选（未处理 / 已处理）
- 列表：预警时间、老人姓名、情感状态、预警等级、操作（标记已处理）
- 右侧：快捷操作（批量处理）

## 7. 老人信息管理页

- 搜索 + 添加老人按钮
- 表格：姓名、年龄、监护人、联系方式、授权状态、操作
- 弹窗：新增 / 编辑信息、隐私授权开关

## 8. 系统设置页

- 账号信息
- 预警阈值设置
- 数据隐私设置
- 推送方式（短信 / 站内/ 邮件）
	- 若选择邮件，则给出填写邮件授权码的输入框
- 版本信息

# 三、布局规范（前端直接用）

- 宽度：**1200px–1400px 居中**
- 侧边栏宽度：**220px**
- 卡片间距：**16px–24px**
- 背景色：浅灰 #f5f7fa
- 卡片白色 #fff
- 主题色：橙色与夕阳金

# 四、移动端极简布局（可选）

- 顶部导航汉堡菜单
- 内容单列流式布局
- 图表自适应缩小
- 按钮放大便于点击
