# 一、核心功能（必须有）

1. **用户登录 / 注册**
    
    - 家属 / 护理员 / 管理员角色区分
    - 手机号 / 验证码/邮箱登录
    - 权限控制（老人数据仅授权可见）
    
2. **老人信息管理**
    
    - 老人基本信息录入、编辑
    - 监护人信息绑定
    - 隐私授权状态展示
    
3. **多模态数据实时采集入口**
    
    - 语音录制 / 上传
    - 图像 / 视频上传
    - 文本输入（对话、留言）
    - 传感器数据对接展示（光照、声音等）
    
4. **情感分析结果展示**
    
    - 当前情感状态：开心、平静、低落、焦虑、愤怒等
    - 情感置信度分数
    - 多模态判断依据（语音 / 图像 / 文本分别得分）
    
5. **数据可视化大屏**
    
    - 情感趋势曲线图（日 / 周 / 月）
    - 情感占比饼图 / 柱状图
    - 历史情感记录时间轴
    - 心理健康评分仪表盘
    
6. **智能预警与提醒**
    
    - 负面情绪自动预警（弹窗 + 提示）
    - 异常状态推送（邮件 / 短信 / 站内信）
    - 预警历史记录与处理状态
    
7. **数据安全与隐私**
    
    - 数据加密展示
    - 授权管理（开启 / 关闭采集）
    - 数据删除 / 导出功能
    - 操作日志记录
    

---

# 二、管理后台功能（管理员用）

1. **用户管理**
    
    - 账号审核、禁用、权限分配
    
2. **模型状态监控**
    
    - 模型识别准确率
    - 推理耗时、服务状态
    
3. **数据管理**
    
    - 数据集查看、清洗、标注入口
    - 数据统计与报表导出
    
4. **系统设置**
    
    - 预警阈值配置
    - 推送方式设置
    - 版本更新日志
    

---

# 三、扩展功能（可选，加分项）

1. **亲情互动**
    
    - 家属留言板
    - 语音问候发送
    
2. **健康建议**
    
    - 根据情感状态给出心理关怀建议
    
3. **多端适配**
    
    - 手机端 / 平板 / 电脑自适应
    
4. **数据导出**
    
    - 周报 / 月报 PDF 导出
    
5. **系统日志**
    
    - 登录日志、操作日志、异常日志

- 顶部导航栏
