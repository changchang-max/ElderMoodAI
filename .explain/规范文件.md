# 规范文件（供 Agent 阅读）

## 核心指令

### 1. 对话记录要求

所有用户输入的命令以及 Agent 对代码造成的修改**必须**保存在 `ElderMoodAI/.explain/对话记录.md` 文件中。

### 2. 记录格式规范

#### 2.1 用户命令记录

每次用户输入指令时，必须记录以下内容：

```
## [序号] - YYYY-MM-DD HH:mm:ss

### 用户指令
[用户输入的原始命令原文]

### 执行结果
[执行结果的简要说明]
```

#### 2.2 代码修改记录

每次 Agent 对代码进行修改时，必须记录以下内容：

```
### 代码修改
- 修改文件: [详细路径及文件名]
- 修改类型: [新增/编辑/删除]
- 修改行数: 第 [行号] 行
- 修改内容: [精简版说明]
```

#### 2.3 系统指令记录

如果 Agent 执行了系统命令（如终端命令、脚本执行等），必须记录：

```
### 系统指令
- 指令: [具体执行的命令]
- 执行结果: [成功/失败 + 简要输出]
```

```
### 用户指令
帮我启动项目

### 执行结果
项目已在 http://localhost:5173 启动成功
```

```
## 2 - 2026-05-06 14:35:00

### 用户指令
创建一个登录页面

### 代码修改
- 修改文件: ElderMoodAI/frontend/src/views/Login.vue
- 修改类型: 新增
- 修改行数: 第 1-150 行
- 修改内容: 创建登录页面组件，包含邮箱/手机号登录表单
```

### 示例 3：系统指令

```
## 3 - 2026-05-06 14:40:00

### 用户指令
安装依赖

### 系统指令
- 指令: npm install --prefix ElderMoodAI/frontend
- 执行结果: 成功，安装 154 个包

### 代码修改
- 修改文件: ElderMoodAI/frontend/package.json
- 修改类型: 新增
- 修改行数: 全文
- 修改内容: 定义项目依赖（vue, element-plus, echarts 等）
```

## 执行要求

1. **实时记录**：每次用户输入后，立即更新对话记录文件
2. **保留原文**：用户指令必须保留原始文本
3. **精简修改**：代码修改说明只需简要描述，不需要完整代码
4. **详细定位**：必须列出具体的文件路径和行号
5. **时间格式**：使用 ISO 格式 `YYYY-MM-DD HH:MM:SS`
